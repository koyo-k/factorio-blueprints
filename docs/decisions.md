## 仮決め（質問せずにおすすめ側で決めた点）

| 日付 | 内容 | 理由 |
| --- | --- | --- |
| 2026-11-16 | 目標は「ロケット 1 発の発射」（ロケット部品 100 個）。衛星（satellite）は作らない | `fbp entity rocket-silo` の rocket_parts_required = 100。衛星は宇宙サイエンス用で、発射そのものには要らない（発射で勝利になる点は記憶に基づく。最初の発射時にゲーム内で確認する） |
| 2026-11-16 | サイエンスの生産量: 赤 36/分（既存の red-science）、緑 30/分、青 15/分、紫 10/分、黄 10/分 | 「最小限」の解釈。研究所 12〜15 台で、ロケットサイロまでの研究が約 7.5 時間（下の roadmap の見積もり。未実測）。赤・緑だけの研究が多い序盤だけ速くし、後半は研究所の時間（1 単位 30〜60 秒）が律速なので 10/分で足りる |
| 2026-11-16 | ロケット部品の材料（処理ユニット・軽量構造材・ロケット燃料）は各 10/分 = ロケット部品 1/分。黄サイエンス用の処理ユニット・軽量構造材ラインを流用する | サイロの研究が終わると黄サイエンスは不要になるため、同じラインを順に使い回せる。100 部品で約 100 分 |
| 2026-11-16 | 機械は組立機2、ベルトは黄ベルト、製錬は石の炉（燃料の石炭はベルトのもう片側レーンで自動供給） | 組立機3 はロケットまでの研究経路に含まれない（automation-3 は前提に無い）。電気炉は紫サイエンスの材料として作るが、製錬は最小限の規模なら石の炉で足りる |
| 2026-11-16 | ロボットの段階は 2 つに分かれる。青サイエンス後に建設ロボット（construction-robotics）と物流ロボット（logistic-robotics）、黄サイエンス後に要求チェスト（logistic-system） | 要求チェスト（requester-chest）は logistic-system（黄サイエンス 500）の解放物。それまではロボットが機械へ物を届けられないので、ライン間はベルトでつなぎ、ロボットは建設と「モール → 保管」に使う。logistic-system 以降に作るラインと、ベルトでつないだ区間の置き換えは要求チェストでつなぐ |
| 2026-11-16 | 個人用ロボットステーション（personal-roboport-equipment）とモジュラーアーマーを研究し、一度だけ手で作って着る | 「最初からなるべくロボット」に沿う。ロボットステーション網の外（採掘場・防衛線）にも Blueprint を貼るだけで建てられる。一度きりの手作業なので方針に反しない |
| 2026-11-16 | 防衛: 機銃タレット＋石の壁、弾薬はベルトで配る（序盤は通常弾、military-2 後は徹甲弾）。研究は physical-projectile-damage 1〜2、weapon-shooting-speed 1〜2 まで。軍事サイエンスは作らない | 最小限の規模では汚染範囲が狭く、序盤〜中盤の攻撃は機銃＋徹甲弾で防げる見込み（未実測。sim は敵を再現しない）。補修はロボットが修理パックで行う |
| 2026-11-16 | 後半のモジュール: 生産力モジュール1 をロケットサイロ（4 枠）と、処理ユニット・軽量構造材・ロケット燃料の組立機（各 2 枠）に入れる。ビーコンは使わない。モジュール3 は研究するだけで作らない | 生産力モジュール1 は紫サイエンスの材料として元々ラインがあり、流用できる。速度モジュール3／生産力モジュール3 はサイロ研究の前提だが、アイテムとしては不要（`fbp recipe rocket-silo` / `rocket-part` の材料に含まれない） |
