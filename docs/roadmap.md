# ロケットまでの計画（roadmap）

前提は `docs/decisions.md`（規模: のんびり最小限 / 敵あり / なるべくロボット / 鉄道なし / モジュールは後半だけ / 1 回の依頼で 1 つずつ）。
数値はすべて Factorio 2.1.24（base のみ）のデータから `fbp recipe` / `fbp rates` / `fbp entity` と
`technology.lua` で引いたもの。「実測」と書いた値以外は理論値・見積もりで、未達成。

進め方: 「roadmap の次を作って」と言われたら、下の表で **状態が「未着手」の先頭** を 1 つ作り
（`.claude/skills/blueprint/SKILL.md` の手順 1〜7）、その行の実測値・残る手作業・状態を更新する。

状態の書き方: `未着手` / `実測済み（値）` / `静的検証のみ・未実測`（採掘・発電・汲み上げ・敵など sim で測れないもの） / `手作業`（Blueprint を作らない）。

## 1. ゴールと必要量

**ゴール**: ロケットサイロでロケット部品 100 個を作り、ロケットを 1 発打ち上げる（衛星なし）。

### ロケット本体（`fbp recipe rocket-part` / `rocket-silo`、`fbp entity rocket-silo`）

| 品目 | 1 発あたり | 備考 |
| --- | --- | --- |
| ロケット部品 | 100 個（サイロ内で作る。1 個 3 秒） | 1 個 = 処理ユニット 10 + 軽量構造材 10 + ロケット燃料 10 |
| 処理ユニット | 1,000 + サイロ用 200 | 1 個 = 電子回路 20 + 発展回路 2 + 硫酸 5（10 秒、流体レシピ） |
| 軽量構造材 | 1,000 | 1 個 = 鋼材 2 + 銅板 20 + プラスチック 5（15 秒） |
| ロケット燃料 | 1,000 | 1 個 = 固形燃料 10 + 軽油 10（15 秒、流体レシピ） |
| ロケットサイロ（1 台） | 鋼材 1,000、コンクリート 1,000、パイプ 100、処理ユニット 200、電気エンジン 200 | 一度きり |

部品 100 個分の原料（`fbp rates rocket-part 100`、板と流体で止めた合計）: 銅板 60,000、鉄板 24,000、
プラスチック 9,000、固形燃料 10,000、鋼材 2,000、軽油 10,000、硫酸 5,000。
サイロ 1 台はさらに 銅板 8,600、鉄板 6,100、鋼材 1,200、プラスチック 800、石レンガ 500、潤滑油 3,000 ほか。
**銅が圧倒的に多い**（軽量構造材が 1 個で銅板 20）。銅の採掘・製錬は鉄より多めに用意する。

### 研究（technology.lua の前提をたどった合計。ロケットサイロ＋ロボット・防衛・便利系）

| パック | 合計（約） | 生産量の目標 | 主な用途 |
| --- | --- | --- | --- |
| 赤（automation） | 7,300 | 36/分 | 全研究 |
| 緑（logistic） | 6,900 | 30/分 | 全研究 |
| 青（chemical） | 4,200 | 15/分 | 石油・ロボット以降 |
| 紫（production） | 1,600 | 10/分 | モジュール3・サイロ |
| 黄（utility） | 1,500 | 10/分 | logistic-system（500）・サイロ（1,000） |

- ロケットサイロの研究だけで 1,000 単位 × 60 秒（5 色）。前提に speed-module-3 / productivity-module-3（各 300 単位、紫を使う）がある。
- 研究所は 12〜15 台（`fbp entity lab`: 研究速度 1）。上の生産量で研究に約 7.5 時間（見積もり、未実測）。
- 研究に含めるもの（ロケット経路の外）: construction-robotics、logistic-robotics、logistic-system、
  personal-roboport-equipment（＋modular-armor、solar-panel-equipment）、gun-turret、stone-wall、military、military-2、
  physical-projectile-damage 1〜2、weapon-shooting-speed 1〜2、repair-pack、fast-inserter、electric-mining-drill、logistics。

### 研究の順番（おおまか）

1. 自動化（automation）→ electric-mining-drill → logistics → 赤パック解放後に military / gun-turret / stone-wall / repair-pack
2. logistic-science-pack → steel-processing → automation-2 → fast-inserter → military-2（徹甲弾）→ 射撃系 1〜2
3. oil-gathering（→ 原油を掘ると oil-processing が解放）→ plastics / advanced-circuit / sulfur-processing → chemical-science-pack
4. advanced-oil-processing → lubricant / battery / electric-engine → **robotics → construction-robotics → logistic-robotics → personal-roboport-equipment**（青が出たら最優先）
5. production-science-pack 系（modules / productivity-module / advanced-material-processing-2 / railway）
6. processing-unit / low-density-structure / utility-science-pack → **logistic-system**（黄が出たら最優先）
7. concrete / rocket-fuel / solar-energy / electric-energy-accumulators / radar / モジュール3 → rocket-silo

## 2. 段階ごとの計画

列の意味: **Blueprint** = 貼るもの（`blueprints/<name>`）、**入力 → 出力**、**つなぎ方** = 前後のラインとの接続、
**残る手作業** = その段階で繰り返しプレイヤーに残る運搬・製作、**状態**。

### 段階 0: 手作業での立ち上げ（Blueprint なし）

一度きりの手作業なので多くてよい。目的は段階 1 の設備を貼れるだけの資材と電力を作ること。

| やること | 状態 |
| --- | --- |
| 燃料式ドリル＋石の炉で鉄・銅・石・石炭を掘り始める。手で燃料を入れる | 手作業 |
| 蒸気発電の最初の 1 組（オフショアポンプ・ボイラー・蒸気機関）を手で建てる | 手作業 |
| 研究所を数台手で作り、赤パックを手で作って automation / electric-mining-drill / logistics を研究 | 手作業 |
| 段階 1 の Blueprint に要るベルト・インサータ・電柱・組立機1・電動ドリル・炉を手で作る | 手作業 |

## 5. sim で測れないもの

採掘（`mining-ore`）、発電（`steam-power`）、汲み上げ（`oil-pumpjacks`）、ロボットの活動範囲（`roboport-grid`）、
防衛力（`defense-line` の敵との戦闘）。これらは作っても「静的検証のみ・未実測」と書く。
